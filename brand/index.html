選ぶためのブランド案

いまのサイトの見た目は変えていません。ここは、印・色・文字・図の候補です。A がいま入っている組み合わせ。B と C は別案です。文章も図も、参考サイトからは写していません。

01 Concept

考え方

核は「つくりながら、考える。」と Make / Run / Rethink。新しいことを試し続ける人、という印象に寄せた三つの言い方です。

A · いまの軸

軸の上で、少し外す

つくりながら、考える。試みは、決めた軸から一本だけ外れる。

Make / Run / Rethink. は、その一本の動き。

B

線が、次の形を呼ぶ

新しいことは、一本の線から始まる。残すのは、もう一度考えたもの。

作る、走らせる、考え直す。順番が仕事になる。

C

組んでは、ほどく

同じ組みを繰り返さない。組んではほどき、また組む。

試行は失敗ではなく、次のグリッドのためのずれ。

02 Logo

印

A は旧い紫の正方形（十字と斜め）を三本に削ったもの。B と C は別の作り方。それぞれ、横組み・縦組み・印だけ、明地と暗地、16 / 24 / 32px。

A · 軸と試し線

縦と横が軸。斜め一本だけ色を変える。クリアスペースは線幅1本分。最小は 16px。

B · 面

点が割れて面になる。K の形は面のすき間で読む。最小は 24px。16px では面が潰れるので、そこでは使わない。

C · ずれた格子

3×3 の点。一本だけ格子から外れる。最小は 16px。

してよい: 明地に墨、暗地に紙色。試し線だけアクセント。
しない: 傾ける、線を細く伸ばす、試し線以外を塗る、写真の上に板なしで置く。

04 Type

書体

無料のウェブフォント。日本語、ラテン、等幅の三つ。下はヒーローの一文と、短い本文。

A · Syne / Noto Sans JP / Plex Mono
つくりながら、考える。 Make / Run / Rethink.

名前は Syne。日本語の見出しと本文は Noto Sans JP。日付と英語の一行は IBM Plex Mono。

B · Instrument Sans / Zen Kaku Gothic / Plex Mono
つくりながら、考える。 Make / Run / Rethink.

日本語もラテンもゴシックで揃える。Instrument Sans はナビと英字の見出し。静かな建築の組版。

C · Newsreader / Shippori Mincho / Space Mono
つくりながら、考える。 Make / Run / Rethink.

一文は明朝。英字の見出しは Newsreader。等幅は Space Mono。編集された紙面に近い。

05 Graphic

図と写真

A · 軸の場

直角の面。試し線は一枚だけ斜め。写真の上では白、透明度 50% まで。

B · 面

点から割った面。作品のボロノイ時計と同じ家系。塗りつぶしはしない。

C · ずれた格子

等間隔の点。一つだけずらし、そこへ線を引く。図面の補助線として使う。

写真: 色は撮ったまま。一覧では枠いっぱいに置き、ホバーで彩度だけ落とす。人物の顔は切らない。図は写真の端に重ね、中央の被写体にはかけない。
