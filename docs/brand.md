# Kota Okugawa — VI

採用した組み合わせのルール。核の一文は「つくりながら、考える。」。英語は Make / Run / Rethink.。考え方は C、印は B、色は A、書体は B、図は B。比較の記録は `brand/index.html`（`noindex`、フッターの「ブランド案」）。

## コンセプト

組んでは、ほどく。

同じ組みを繰り返さない。組んではほどき、また組む。試行は失敗ではなく、次の面のためのずれ。印の二枚の面と、画面に置く開いた面は、そのずれを形にしたもの。

一文と英語の一行は変えない。電話番号は置かない。

## ロゴ

二枚の面。すき間が K に読める。塗りは墨一色。アクセントは印に塗らない。

基準グリッドは 32。

- 左の面: `M4 3h8v26H4z`（x 4–12、y 3–29）
- 右の面: `M16 3h11L20.2 16 27 29H16l-4.4-13z`（外は x 27、腰は x 11.6 で左の面に接する）

クリアスペースは、グリッド 4（面と面のすき間と同じ）を印の外側に空ける。これより近くに写真や文字を置かない。

最小は 24px。24px 未満では面のすき間が潰れるので、印はこの形のまま縮めない。

組み合わせは一つ。

1. 左に印（高さ 28px）
2. すき間 0.65rem
3. 右に `Kota Okugawa`。Instrument Sans、太さ 600、字間 -0.03em

縦位置はキャップハイトで揃える。名前なしの印を本文の飾りにしない。

### 16px

ファビコンだけ、面を重ねた簡略形を使う。地は paper、形は ink。ファイルは `assets/favicon.svg`。

- 左: `M3 3h11v26H3z`
- 右: `M13 3h16L22 16l7 13H13L7 16z`

簡略形をヘッダーや名刺のサイズに拡大しない。通常の印を 16px に縮小しない。

ink / paper は 16.5:1。muted / paper は 6.5:1。accent / paper は 3.6:1 なので、アクセントは本文・見出し・番号に使わない。

明地では印は ink。暗地（写真の上のヘッダー、共有画像）では印は paper。

## 図

開いた面。線だけで、塗りつぶさない。作品のボロノイ時計と同じ家系。面の共有辺のうち一本だけ accent。

置く場所は、各節見出しの右と、写真がまだ無い枠。ヒーローの最初の画面には置かない。そこにあるのは写真、ロゴタイプ、一文と英語の一行。本文の上には重ねない。写真の中央の被写体にはかけない。

## 写真

色は撮ったまま。作品一覧は枠いっぱいに置き、ホバーで彩度だけ落とす。拡大もしない。人物の顔は切らない。

## してよい / しない

してよい。

- 明地に ink、暗地に paper
- アクセントはタイプのカーソル、現在地の下線、面の一本
- 16px では簡略形だけ
- 動きを減らす設定では、英語を最初から全文にし、出現の動きを止める

しない。

- 印を傾ける、線にする、片方の面だけ accent にする
- 通常の印を 24px 未満で使う。簡略形を 24px 以上に拡大する
- アクセントで文字を書く
- 面を塗りつぶす
- 電話番号を載せる
- 紫の旧マークを新しい画面に戻す

## 置き方

- ヒーロー: 写真、下左に名前と一文と英語。印はヘッダーの下、右に余白のある領域。左の面は錨で動かさない。右の面だけ引っ張り、窯の線と、英語と同じ語がすき間に出る。ヘッダーの 28px の印はナビ用に残す。開いた面の図は最初の画面には置かない
- トップの続きは作品の面だけ。画面いっぱい。ドラッグで組み直す。動きを減らす設定では、写真とリンクの一覧。その下はフッター
- ヘッダー: ロゴタイプ左。デスクトップは右に Profile / Work / Thoughts / Personal / Contact。五つの短い英語が並ぶので、広い画面ではハンバーガーにしない。幅が狭いときはその並びを隠し、右上の線のアイコンが × になる。全画面の墨地に、章番号つきの大きなリンク。今いるページの番号だけ accent。Mail と GitHub を下に置く。下のバーは置かない
- ファビコン: `assets/favicon.svg`
- 共有画像: `assets/og.png`。地は ink。印、一文、英語の一行、名前。右に開いた面
- 作品一覧: 写真、日付、名前、短い一行。2列
- 考え: 大きな引用
- Football & Photo: 最初の写真を大きく。空の枠は番号と面
