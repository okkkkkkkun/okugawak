# Kota Okugawa — VI

同業者と社内の人に残るための見た目のルール。核は一文、「つくりながら、考える。」。印は、旧サイトの紫の正方形マーク（十字と一本の斜め）を、線三本にまで削ったもの。歴史は捨てず、使う面を減らす。

## コンセプト

旧マークの十字は、軸。斜めの一本は、そこから外へ出る試み。ノートの罫が書き手に寄り添うように、この三本は画面の端や見出しの番号にだけ現れる。言葉で説明しなくても、「組んで、少し外す」が伝わることを優先する。

要素には名前を付ける。

- 軸（じく）: 縦一本、横一本。墨色。
- 試し線: 軸に交わる斜め一本。アクセント色。マークの中ではこの一本だけ色を変える。

## ロゴタイプの作り

基準グリッドは 32。線の太さは 4。縦は x=14、横は y=14、試し線は左下から右上へ、幅 4 の帯。

クリアスペースは、マークの周囲に線の太さ 1 本分（4）。これより近くに写真や文字を置かない。

組み合わせは一つだけ。

1. 左にマーク（高さ 28px）
2. すき間 0.65rem
3. 右に `Kota Okugawa`。Syne、太さ 700、字間 -0.04em

縦位置はキャップハイトで揃える。マーク単体で使うのは、ファビコンと、極小のアイコンだけ。名前なしのマークを本文の中に飾らない。

傾けない。アウトラインを変えない。試し線以外をアクセント色にしない。紫の旧マークは、新しい画面では使わない。

## 色

| paper | `#f6f3ee` | 地。旧サイトの暗いグレーから、紙へ戻した |
| paper-2 | `#e7e2d9` | 写真が来る前の面、空の写真枠 |

面積のほとんどは paper と ink。accent は点と一本の線。

## 文字

- 名前と大見出しのラテン: Syne
- 日本語: Noto Sans JP。ヒーローは 700、本文は 400、行間 1.9、行長は 40rem まで
- デジタル: IBM Plex Mono。`Make / Run / Rethink.`、日付、ナビ

ヒーローの日本語は、文字サイズの約 6.4 字で折り返す。「つくりながら、」と「考える。」の二行になる。

## 動き

英語の一行は 21 字を等幅でタイプする。試し線のカーソルだけ点滅する。カバーの補助線はゆっくり動く。

`prefers-reduced-motion: reduce` では、英語は最初から全文、線は止める、出現の動きもしない。
